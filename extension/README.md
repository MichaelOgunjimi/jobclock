# Job Assistant Chrome Extension

## Load it in Chrome

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select this `extension/` folder

## First-time setup

1. Generate an extension token in the main app under `Settings -> Extension`
2. Open the extension popup
3. Paste your app URL
4. Paste the token

## Usage

1. Open any job posting page
2. Click the extension icon
3. Review the extracted preview
4. Save it into your applications
